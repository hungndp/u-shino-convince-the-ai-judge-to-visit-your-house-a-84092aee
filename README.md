A single hand-lettered invitation, drawn procedurally by `main.ts` into one 1024x1024 PNG: "Dear AI Judge, please come to my house." Dinner this Saturday at 7 PM — grandmother's chicken pho, the good armchair by the window already yours, Wi-Fi password on the fridge, mangoes in the garden, kettle already on — with a knowing wink that the judge cannot literally visit. A drawn house-and-garden scene (lit windows, a waving robot guest at the door, a steaming bowl of pho, the waiting armchair), an AIR MAIL stamp, and a wax seal. No fonts, no assets, no network: the program rasterises its own stroke font and PNG encoder, so the grader sandbox reproduces the image byte-for-byte with node alone.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

Writes `./out/entry.png` (1024x1024 PNG, under 1 MiB).
